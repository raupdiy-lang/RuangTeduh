# RuangTeduh

Next.js 14 emotional support chatbot.

## Setup
1. Copy `.env.example` to `.env.local` and fill keys.
2. Run `npm install`
3. Run SQL in `supabase/schema.sql`
4. Start app with `npm run dev`

## Deploy (Vercel)
- Import repo to Vercel
- Add environment variables
- Deploy with default Next.js build settings
